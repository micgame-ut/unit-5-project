# Reference Phase

1. Search for references that resemble the request (games, videos/GIFs, devlogs, tutorials, shader breakdowns).
2. Compile them into one HTML page (artifact if available, otherwise `reference/<Feature>_Refs.html`). Each entry includes:
   - Checkbox, thumbnail/link, source
   - 1-line note on what it demonstrates
   - Notes field for Developer comments
3. Wait for the Developer to check off what matches their vision. Summarize the chosen direction in 2–4 bullets and confirm before building.
4. Log every source you end up using in `research.md` → Sources and credits.
