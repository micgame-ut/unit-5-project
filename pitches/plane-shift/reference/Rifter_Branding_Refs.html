Rifter: branding references

Direction: the game world is a book. Toska lives on one page, dimensions are the pages, the player flips between them, and a Rift is a tear through a page. Check what matches your vision, add notes, then press Build summary and paste the result into chat.

No thumbnails: I did not fetch images I could not verify. Entries marked search are search links, not confirmed pages.

A. Games with a book / paper / layered-image feel

annapurna.com · Annapurna Interactive
Puzzles built from stacked and moved hand-drawn images. Moving an image with an opening onto another turns it into a mask. Close to the Rift-as-window idea.
Game Developer article · Game Informer preview
Storybook tone: black line art on warm off-white (not pure white, so it reads as paper), with story pages hidden on walls.
search · Media Molecule
A world made of paper: folded, torn and cut-out surfaces. Shows tearing as a core visual and interaction.
logo/font breakdown · Nintendo / Intelligent Systems
Layered paper cut-out look, including the wordmark: thick lettering with edge and shadow effects that read as cut paper.
search · Polytron
2D platforming with perspective shifts. Already in your design doc as a reference for changing views of the same space.
